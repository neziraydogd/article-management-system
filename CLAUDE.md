# Article Management System

## Project

Spring Boot Article Management System.

The project is being developed as a learning project for exploring AI Agent development workflows and project-level guidance.

## Technology

* Java 17
* Spring Boot 4.1.0
* Maven
* H2
* Lombok

## Project State

The project is in early development.

The application currently contains only the initial Spring Boot project structure. 
Domain models and business functionality will be introduced incrementally.

## Architecture

The project currently follows the standard Spring Boot project structure.

Current package:

```text
com.na.article
```

Application-specific domain and application code will be introduced under this package as the project evolves.

## Development Conventions

The project is currently establishing its conventions.

Follow existing project conventions when they exist.

Do not assume additional architectural conventions that have not yet been established by the project.

## Build & Test

Run tests with:

```bash
mvn test
```

Run the application with:

```bash
mvn spring-boot:run
```
